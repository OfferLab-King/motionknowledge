# DCF reference project artifacts

Checked-in immutable artifacts of the "What is a Discounted Cash Flow?"
reference project, generated deterministically by the mock provider. They are
the canonical example payloads and the acceptance fixture for the product.

- project.json — project record
- sources.json — supplied source document
- claims.json — research claims with source links
- lesson.json — lesson plan
- script.json — script with chapters
- storyboard.json — storyboard with scenes
